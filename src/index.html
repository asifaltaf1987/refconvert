    About and privacy
    
    
    Reference Converter splits a reference list into single references, reads authors, title, source, year, volume, issue, pages, publisher and DOI, and lets you correct each record before export.
    
    
    Privacy
    
    
    The page has no server component, no tracking and no cookies. Text and files stay in your browser. Your current work is kept in this browser's local storage until you select Clear.
    
    
    When you select Check with Crossref, DOIs, or for records without a DOI the reference text, are sent to the Crossref REST API (api.crossref.org).
    
    
    Accuracy
    
    
    Parsing uses rules for common styles. Check records marked in amber. Crossref completes records that have a DOI and finds DOIs for many journal articles.
